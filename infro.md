# Calculator Project, Development Log

**Language:** C  
**Compiler:** GCC  
**Status:** In Development

## Current Features
- [x] Main menu
- [x] Currency converter
- [x] Length converter
- [x] Mass converter

## Development Log

- Added a main menu to navigate between converters.
- Implemented a currency converter.
- Implemented a length converter.
- Implemented a mass converter.
- Organized the project into multiple C source files and a header file.


## How to Compile and Run

Compile the project from the terminal:

```bash
gcc main_menu.c unit.c weight.c currency.c -o Calculator.exe
```

Run on Windows:

```powershell
.\Calculator.exe
```
